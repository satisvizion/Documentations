Rate Prompt

The optional Rate Prompt panel in Demo/HLK_Showcase.unity uses the kit's registered review service. Open the showcase and select Rate Prompt in its dashboard menu.

Modes and setup

Keep review requests Disabled when unused. Dummy mode simulates requests. A native provider requires its separately installed official dependency, your own application identifiers and a supported device. Editor and WebGL demonstrations do not establish native Android or iOS behavior.

Panel controls

  • Try Gated Request follows the configured eligibility rules and reports a blocking reason when appropriate.
  • Force Request Review bypasses the kit's eligibility gates for testing. It still respects Disabled mode and platform restrictions; it cannot force a platform-owned review dialog to appear.
  • Review with pre-prompt demonstrates the optional Popup Stack confirmation. Cancelling or closing that popup does not request a review.
  • Request without pre-prompt is a separate direct-request test path.
  • Reset Gates asks for confirmation, then clears only local review-history signals. It does not reset the game or change the platform's review behavior.
  • Open Store Listing opens the configured listing and may leave the game.

These force and reset controls belong to the showcase. Configure the player-facing flow for your own game, and verify native behavior on a supported device. A successful return value is not evidence that a rating was submitted.
