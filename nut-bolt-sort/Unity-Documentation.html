Nut Bolt Sort

Developer manual · Version 1.0.1 · SatisVizion · Documentation revised 26 October 2026

Overview and included content

Tap a source bolt to lift its matching top nuts, then tap a compatible destination bolt. Group every colour together to clear the bench.

This is an editable Unity game template and starting point for your own title. Customize the visuals, copy, level progression and release settings for your audience, then test your changes. The included Android demo is a showcase build; it is not a signing key or a production store submission.

URP procedural workshop meshes with uGUI; tap-based sort puzzle The campaign contains 25 authored levels and game-specific procedural continuation. The included service kit is HyperCasual LiveOps Kit. Ads ship in Dummy/simulated mode and IAP is Disabled; third-party advertising/billing SDKs are not bundled.

Installation and first successful play

  1. Back up your project and extract the main ZIP completely. Read Documentation/Documentation.html before importing the package. Offline documents do not require the hosted page to be available.
  2. Install Unity 6000.0.62f1 through Unity Hub. Add Android Build Support (including the matching SDK, NDK and OpenJDK) if building Android, and WebGL Build Support if building browser demos. A supplied source project can be opened with Add project in Unity Hub.
  3. For package import into a new project, select a Universal Render Pipeline template. Use Assets > Import Package > Custom Package and import the complete package. Do not omit the private game Kit, HyperCasualLiveOpsKit, fonts, settings, scenes or their .meta files.
  4. Check Window > Package Manager: Universal RP 17.0.4, Unity UI 2.0.0 and Input System 1.14.2. Standard Unity modules include com.unity.modules.screencapture and com.unity.modules.androidjni. Let Unity finish compilation before opening a scene.
  5. Set Edit > Project Settings > Player > Other Settings > Active Input Handling to Both manually. Restart if Unity requests it. The documented setup is a user action; do not rely on an import hook changing a buyer's Project Settings.
  6. In Edit > Project Settings > Graphics select the supplied URP asset, and check the pipeline assignment for the active Quality level. Retain the packaged Settings assets and GUID references. A pink scene usually indicates a missing pipeline or shader assignment.
  7. Open Assets/SatisVizionNutSort/Games/NutSort/Scenes/NutSort_Mobile.unity. Press Play, focus the Game view, and follow the first-level tutorial: Tap a source bolt to lift its matching top nuts, then tap a compatible destination bolt. Group every colour together to clear the bench.
  8. Stop Play mode before editing source or authored content. Open the landscape scene Assets/SatisVizionNutSort/Games/NutSort/Scenes/NutSort_WebGL.unity and verify the alternate layout as well. Runtime-created UI changes made only in Play mode are not a saved reskin.

2. Change a visible HUD label

Open Assets/SatisVizionNutSort/Games/NutSort/Scripts/NutSortGame.Hud.cs, find BuildHud and locate this exact source line:

_levelText = HzUI.Label("Level", _col, "LEVEL " + Level, 86, Color.white);

To call levels stages, change the display string while preserving the level expression and formatting:

_levelText = HzUI.Label("Level", _col, "Stage " + Level, 86, Color.white);

This is a targeted edit to the displayed string, not a global search/replace of object names. HzUI.Label("Lvl", parent, "LEVEL " + Level, ...) uses its first string as a hierarchy/object name and its third argument as visible text. In assignments such as _levelTxt.text = ..., edit only the literal part; retain the number, interpolation braces, arithmetic, conditional branches and formatting.

4. What the shared localization guide does and does not cover

The shared HyperCasual LiveOps Kit localization guide concerns UI and content that use that kit's localization service. This game's literal strings in the files above are not automatically replaced by adding entries to an HLK table. For one-language reskinning, edit the literals and data shown here. For runtime language selection, explicitly route those game display assignments through your chosen lookup service, provide keys for each caption, and refresh active labels when the language changes. That is an integration task, not a delivered translation toggle.

The landscape title is the two-line string NUT BOLT\nSORT in BuildSides; the portrait level heading is created in BuildHud. Both live in NutSortGame.Hud.cs. Changing Title in NutSortGame.cs alone does not replace that landscape title. Booster display names are in BoostName. Nut colours and material/mesh details are in the view and material-generation code and are separate from the Orange/Blue/Navy/Brass/Cyan HUD constants.

5. Verify the reskin

  1. Launch both supplied scenes with a normal player save. Confirm the edited level heading, game title, settings/help buttons, counters and booster names.
  2. Open a result popup and a refill offer, and replay the first-level and first-booster tutorials using a disposable test profile or the documented developer controls. Confirm that the changed colours remain readable behind all overlays.
  3. Test one valid move, one invalid action, progression to the next level, a retry and one available booster. A text reskin must not change goals, costs, rule checks or resource IDs.
  4. Make a new Android/WebGL test build after source edits. Existing hosted demos and videos will continue to show their previously built appearance until rebuilt; editing this manual alone does not change those binaries.

Gameplay

Click or tap a bolt, then another bolt. Only a matching top colour or an empty bolt can receive a move; available space limits how many nuts transfer. Filled single-colour bolts receive a cap. Rust hides colours until exposed, a key nut opens a padlocked bolt when moved away, and tall bolts hold five nuts.

The first levels guide the basic moves. New mechanics and boosters introduce themselves through popups. Completion awards gears: 20 for a normal level or 40 for a hard level, plus any other earned gears. Progress, charges and settings save locally through PlayerPrefs; WebGL storage depends on the browser profile. When no legal move remains, the recovery popup offers applicable undo/spare/retry actions.

The source renders its workshop, bolts and nuts using procedural meshes and URP materials, with uGUI overlays. The interaction is a tap-based sorting puzzle. Use the supplied scene and camera setup for its workshop presentation.

Level editing

Open Nut Bolt Sort > Level Editor. The editor reads and writes Assets/SatisVizionNutSort/Games/NutSort/Resources/nutsort/Levels/levels.json.

To make a first edit:

  1. Select an existing level in the list and duplicate it, keeping the original tutorial unchanged.
  2. Select a bolt, choose a nut colour, and paint the bolt from bottom to top. Use the erase brush to remove that slot and the nuts above it. Keep colour totals consistent with the bolt capacity.
  3. Adjust bolt capacity, rust, key position and the optional padlocked bolt. The key must be on a different bolt from the lock.
  4. Run the editor's validation/solver controls. Read the actual result; a design difficulty value is a target, not a proof that a player will solve it.
  5. Save the level file. In Play mode open the DEV panel and jump to the new level number. Play the changed board and confirm its intended solution.

The editor supports add, duplicate, delete, reorder, undo and save prompts. Nut Bolt Sort → Validate All Levels is available for authoring validation.

Data format

bolts strings read bottom to top. Lowercase a–l are colours; uppercase marks rust. cap is bolt capacity. lockBolt, keyBolt and keySlot are zero-based; -1 disables the lock/key. hard, breather, tut, hint and difficulty control presentation, guidance and generation intent.

{
  "version": 1,
  "levels": [
    {
      "name": "First Turn",
      "cap": 4,
      "bolts": [
        "aaa",
        "a"
      ],
      "lockBolt": -1,
      "keyBolt": -1,
      "keySlot": -1,
      "hard": false,
      "breather": true,
      "tut": 1,
      "hint": "",
      "difficulty": 0
    }
  ]
}

The top nut is normalised clean by the runtime. A winning bolt is full and all one colour. Keep the model's maximums in mind: 12 colours, 16 bolts and capacity up to 6; the delivered design uses four- and five-nut bolts.

Generation

The editor's Auto Generate controls include count/start, seed, empty bolts, colour range, rust range, difficulty range, breathers, locks, tall bolts, spread layout and replacement. Generate a small batch, inspect its solver/difficulty results, save, then play the new boards.

After the 25 authored levels, NsLevels.Get uses NsGen.Curve and the deterministic seed level * 7919 + 1301. Generated levels cycle through breather, rust, lock, combined and hard recipes. The generator uses bounded solver attempts, alternate seeds, extra room and a constructive fallback. The delivered content is 25 authored levels plus procedural continuation.

Game text versus saved data and service configuration

Game progress, tutorial flags, currency and booster inventory are stored through the private HzSave helper and Unity PlayerPrefs. Search that helper and the main game script for the current key prefix. Changing displayed titles does not require changing those keys. Renaming keys can make an existing player appear to lose progress; plan migration before doing so.

Use a separate test profile when replaying onboarding. Do not use a global DeleteAll operation in a buyer's existing multi-asset project. Developer resets and unlocks should be used deliberately on test saves. Confirm the state after stopping/restarting Play, because an old saved tutorial flag can correctly suppress the popup you expect to see.

The HLK settings asset is Assets/SatisVizionNutSort/HyperCasualLiveOpsKit/Resources/HLK/HLKSettings.asset. Ads default to Dummy and IAP to Disabled. Keep those defaults while reskinning. A production provider requires its real, separately installed SDK, IDs, platform configuration and testing. Optional setup documentation does not mean a provider SDK is included or automatically installed. Keep service identifiers, ad-placement IDs and reward callback semantics separate from translated button text.
