Word Sweep

Swipe through touching letters to spell an English word, then release to submit it. Clearing an entire row or column sweeps a line. Follow the current level goal and its move or time limit.

First run

  1. Install Unity 6000.0.62f1 in Unity Hub. For Android add matching Android Build Support, SDK, NDK and OpenJDK; for browser builds add WebGL Build Support.
  2. Open the supplied standalone project, or create a Unity 6 URP project before importing the buyer package. Required packages: URP 17.0.4, uGUI 2.0.0, Input System 1.14.2, the standard Unity modules, ScreenCapture and AndroidJNI. The standalone project includes its manifest and lock file.
  3. Import all three asset roots: Assets/Games/WordSweep, Assets/HyperCasualLiveOpsKit and Assets/TextMesh Pro. Keep every .meta file and the game's private Kit folder; it is required runtime code.
  4. Set Edit → Project Settings → Player → Other Settings → Active Input Handling = Both and restart Unity if prompted. Run Word Sweep → Setup after package import to select the supplied URP settings.
  5. Open Assets/Games/WordSweep/Scenes/WordSweep_Mobile.unity and press Play. This is the portrait scene. A landscape WebGL scene is also included; use the scene appropriate for your build. Much of the game UI and world are created at runtime.

Gameplay and content

Swipe through touching letters to spell an English word, then release to submit it. Clearing an entire row or column sweeps a line. Follow the current level goal and its move or time limit.

Authored letter boards, English word dictionary, shaped boards, line-sweep goals, scoring, timed and move-limited levels.

The source includes 25 authored levels and seeded procedural continuation. Progress, settings and charges are stored locally with PlayerPrefs. Browser storage depends on the browser profile. The template includes source and editable level data; generated continuation is not advertised as hundreds of individually authored levels.

Boosters

  • Shuffle unlocks at level 3.
  • Hint unlocks at level 6.
  • Gust unlocks at level 9.
  • Sunshine unlocks at level 13.

First-use guidance introduces each booster. Availability depends on the level, current state and remaining charges. Rewarded placements are simulated by default; only a completed reward callback should grant a refill. Use the DEV panel to unlock boosters for authoring, not as a substitute for real progression testing.

Manual editor and generation

Open Word Sweep → Level Editor. Duplicate a level before changing the original tutorial. The authoring file is Assets/Games/WordSweep/Resources/wordsweep/Levels/levels.json.

Paint letters and special tiles, set the board mask/shape, goal, theme and move/time limit. Apply mask changes deliberately. Re-roll ? changes random-letter seed; Freeze ? stores its currently drawn letters. Recompose rebuilds letters and specials while retaining the slot's size, shape tag, goal and limit. Validate that the board has usable English words and that the goal is achievable, then save and Quick test. Generated boards continue beyond the authored set. Changing to another language requires a compatible dictionary, word rules and fonts; it is not an automatic localisation switch.

The included editor supports saving, duplication and ordering, and provides generation and validation controls appropriate for this game. Read the actual validation result; a difficulty target is not a guarantee of player success. Use a repeatable seed when comparing generated variants. Test changed boards in Play mode.

Customisation

Game logic is under Scripts; presentation and UI are in the game's Game partial classes. Artwork, sound effects, music and levels are under Resources/wordsweep. Shared UI, audio, ad and haptic helpers live in Kit/Runtime; font files and placements are under Kit/Resources/wordsweep/kit. Keep resource paths unless you update every matching code reference.

Change Company Name, Product Name, Version and the Android application identifier in Player Settings to values you control. Do not publish under com.satisvizion.wordsweep.demo. Assign your own launcher/adaptive icon layers and review the splash screen, in-game title and other branding. Increase Android Bundle Version Code for each released update. Test UI fit, text and touch targets on an actual phone.

LiveOps, ads and haptics

The publisher-owned HyperCasual LiveOps Kit is included. Read its complete offline manual.

Settings: Assets/HyperCasualLiveOpsKit/Resources/HLK/HLKSettings.asset. Shipping defaults are Ads Mode Dummy (0) and IAP Mode Disabled (3). Banner, interstitial and rewarded placements are simulations. No Google Mobile Ads, billing or other vendor SDK is included. Automatic vendor-SDK installers are disabled. The game's own Kit is required code, not an advertising SDK.

To enable a real provider, separately install its official SDK, follow the kit manual, configure your own identifiers, consent and privacy policy, then test the selected platform and all cancellation/failure cases. Do not enable SDK symbols without the corresponding dependency. Optional kit modules are capabilities, not production services already configured for this game. Native vibration needs a supported device; browser haptics and other native services have platform limits.

Development controls

Open DEV, press F2/backquote, or use the kit's top-left multi-tap shortcut. The global panel supports level jumps, booster access, ads and haptics controls. Add HZ_RELEASE to scripting defines when you want these development controls excluded from a consumer build. This does not configure real ads or certify store readiness.

Android release

Use the Mobile scene, portrait orientation and ARM64/IL2CPP with matching Unity tools. The provided APK is a debug-signed development demo, not a production store release. For release turn off Development Build and debugging, choose your own application identifier and review current store API requirements.

In Player → Publishing Settings create or select your own keystore and alias. Securely retain the keystore, alias and passwords for future updates; never redistribute signing secrets. Enable Build App Bundle for a Google Play AAB. Install a release candidate on a physical Android device and check touch, audio, haptics, pause/resume, saves and any enabled provider flows. Complete destination-store ads/data declarations and your privacy policy for the services actually enabled.

WebGL

Build the Mobile scene for a portrait-only demo with the built-in Default template and Brotli decompression fallback. Use Word Sweep → Create Responsive WebGL Page after building and select the output folder. This generates an original responsive page around the complete Build folder. Serve every loader, framework, data and WASM file over HTTP(S); file:// is unsupported. Audio normally starts after a first click/tap.

The two-scene landscape-first route supports ?mobile=1 to switch to the following Mobile scene. The included WebGL build menu uses HLK's non-development local showcase scope. It supports simulated demos; configure your production providers and resolve the kit build-doctor checks for a real service release.

Troubleshooting

  • Missing types: install the required packages and import all three roots, preserving .meta files.
  • Pointer input exception: select Active Input Handling Both and restart Unity.
  • Pink materials: use URP 17.0.4 and run the game's Setup command.
  • Sparse scene in edit mode: world/UI objects are built at runtime; press Play.
  • No real ad revenue: Dummy mode is simulated and no provider SDK is bundled.
  • IAP is unavailable: it is deliberately Disabled by default; configure an official billing integration separately if you need it.
  • Progress persists: use the development reset controls or deliberately clear this product's PlayerPrefs.
  • WebGL does not load from a local file: serve the complete output over HTTP(S).

English word data

The included ENABLE dictionary is public domain. The secondary 3–8 letter candidate list is derived exclusively from that same dictionary and sorted by length and alphabetically; it is not a word-frequency ranking. Rare English words may be accepted. Keep the ENABLE public-domain notice under Kit/Resources/wordsweep/kit/Words. To localise the game, replace both lists consistently, keep their resource paths or update all references, and rerun validation for every authored and generated level. All 25 supplied authored levels passed the included solver with these shipped lists.
