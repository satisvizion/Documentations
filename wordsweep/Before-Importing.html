Word Sweep — before importing

Unity 6000.0.62f1, Universal Render Pipeline 17.0.4.

  1. Create a Unity 6 URP project and install Input System 1.14.2 and uGUI 2.0.0 with the standard Unity modules, ScreenCapture and AndroidJNI.
  2. Import the complete unitypackage, including the game's Kit, HyperCasual LiveOps Kit and TextMesh Pro. Keep all meta files.
  3. Set Active Input Handling to Both and restart the editor if prompted.
  4. Run Word Sweep → Setup. Open Assets/Games/WordSweep/Scenes/WordSweep_Mobile.unity and press Play.
  5. Read the included game Documentation/Documentation.html and HLK manual.

Ads are Dummy/simulated; IAP is Disabled. No advertising, billing or other vendor SDK is bundled. Optional providers require separately installed official SDKs and your own service configuration. The supplied Android demo is debug signed; use your own identifiers and keystore for production releases.

Online manual: https://satisvizion.github.io/Documentations/wordsweep/Documentation.html.
