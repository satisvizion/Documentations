Optional Google SDK setup

HyperCasual LiveOps Kit does not bundle or automatically install Firebase, Google Play Games Services, or their dependency tooling. The runtime adapters remain optional and compile only when the matching vendor SDK and HLK define are present.

Firebase

  1. Back up or commit the project.
  2. Follow Google's current Firebase Unity setup guide.
  3. Install only the Firebase products used by the game and keep all Firebase products on one compatible version.
  4. Add the platform configuration files supplied by Firebase.
  5. Complete the vendor's Android/iOS dependency steps, then enable only the matching HLK integration defines.
  6. Validate consent, account configuration, signing, native builds, and device behavior before release.

Google Play Games Services

  1. Follow Google's current Play Games Services Unity guide.
  2. Configure the app, OAuth/signing identities, testers, and service IDs in Play Console.
  3. Install the supported SDK using the vendor's documented method.
  4. Enable the HLK Play Games integrations only after the SDK is present.
  5. Test sign-in and each enabled service in a signed Android build on a configured device.

HLK does not change package manifests, fetch SDK archives, import vendor packages, run dependency resolution, activate cloud services, create credentials, or alter signing. Those operations remain under the developer's explicit control.
